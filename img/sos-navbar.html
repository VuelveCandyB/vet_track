El logo hereda el color del texto (currentColor): en la barra verde sale blanco automáticamente.

Qué es

Ítem de navegación "SOS" para el navbar (contexto médico/veterinario). Enlace de texto blanco con una microanimación de emergencia: un punto que emite ondas concéntricas y el texto con un doble latido. Llama la atención como acceso de emergencia sin romper el estilo de la barra. No usa imágenes ni librerías — solo texto y CSS.

Código — SosLogo.tsx

App Router · incluye "use client"

"use client";

import Link from "next/link";
import styles from "./SosLogo.module.css";

type SosLogoProps = {
  href?: string;
};

export default function SosLogo({ href = "/sos" }: SosLogoProps) {
  return (
    <Link href={href} className={styles.sosLogo}>
      <span className={styles.sosDot}>
        <span className={styles.ring} />
        <span className={styles.core} />
      </span>
      <span className={styles.sosText}>SOS</span>
    </Link>
  );
}

Estilos y keyframes

.sosLogo {
  position: relative;
  display: inline-flex;
  align-items: center;
  gap: 6px;
  text-decoration: none;
  font-family: Arial, Helvetica, sans-serif;
  color: inherit;
}
.sosDot {
  position: relative;
  display: inline-flex;
  align-items: center;
  justify-content: center;
  width: 9px;
  height: 9px;
}
.ring {
  position: absolute;
  width: 9px; height: 9px;
  border-radius: 50%;
  background: currentColor;
  animation: sosNavRing 1.8s ease-out infinite;
}
.core {
  position: relative;
  width: 7px; height: 7px;
  border-radius: 50%;
  background: currentColor;
}
.sosText {
  font-weight: 700;
  font-size: 15px;
  letter-spacing: .08em;
  transform-origin: center;
  display: inline-block;
  animation: sosNavBeat 1.8s ease-in-out infinite;
}
@keyframes sosNavRing {
  0%   { transform: scale(.6); opacity: .7; }
  80%  { transform: scale(2.1); opacity: 0; }
  100% { transform: scale(2.1); opacity: 0; }
}
@keyframes sosNavBeat {
  0%, 100% { transform: scale(1); }
  12%      { transform: scale(1.12); }
  24%      { transform: scale(1); }
  36%      { transform: scale(1.12); }
  48%      { transform: scale(1); }
}
@media (prefers-reduced-motion: reduce) {
  .ring, .sosText { animation: none; }
}

Cómo integrarlo

  • Crea components/SosLogo.tsx y components/SosLogo.module.css con el código de arriba.
  • Móntalo como último ítem del navbar, después de "Admin":
    <SosLogo href="/sos" />
  • Mantén color: inherit para que herede el blanco del navbar; no fijes el color a mano.
  • Pages Router: quita "use client". Si usas Tailwind/styled-components, adapta conservando los mismos valores y keyframes.
